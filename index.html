THE ADVENTURE BEGINS

PLAY JEOGORI

보내주신 웅장한 대검 일러스트를 메인 간판으로 장착한 정통 다크 판타지 RPG 공식 웹사이트입니다.
왼쪽 메뉴판의 시스템 버튼들을 클릭하면 해당 정보 구역으로 화면이 즉시 부드럽게 자동 스크롤 이동합니다.

CHARACTER CLASS INFO

출시 예정 영웅 및 클래스 정보 도감

여기에 기획 중이신 캐릭터의 영웅 정보(전사, 마법사, 로그 등)의 고유 패시브와 특징 능력치를 타이핑해 유저들에게 공략을 배포하는 구역입니다.

SKILL TREE SYSTEM

스킬 계보도 및 마법 특성 조율

RPG 게임 플레이의 핵심인 액티브 스킬 연계식이나 액션 메커니즘을 게이머들이 사전에 학습하고 연구할 수 있도록 데이터 스펙 가이드를 배치합니다.

CRAFTING & COMBINATION

장비 합성식 및 숨겨진 아이템 레시피

고급 장비 제작법, 특수 합성식 규칙, 혹은 최적의 전략 빌드 조합 공략집 가이드를 카드 형태로 수록하여 정보 허브 공홈의 가치를 강화합니다.

SYSTEM REQUIREMENTS

게임 조작 및 하드웨어 구동 권장사양

게임 빌드 실행에 필요한 최소/권장 그래픽 카드 PC 사양이나 마우스, 키보드 단축키 기본 세팅법을 배치하여 글로벌 유저들의 원활한 진입을 보장합니다.
